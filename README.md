# HUMIS

## GDES 5342: Interaction Design.

This project was a nice expansion on the material I learned in the previous class last spring. It felt like we were beginning to think
like modern UX designers in the mobile first view. One struggle I encountered was the placement and nesting of certain elements that
allowed a responsive design. If I had incorrectly laid out certain elements, when I tried to convert from a row to column orientation
they did not shift correctly. It took multiple pages for me to figure out the best way to start a layout of a page. Another issue I 
encountered was overflow issues as the page shrank. I was able to fix it using flex but it took lots of trail and error to figure out 
a solution. That in-between state would benefit from a third tablet layout. I would like to learn how to dynamically make text shrink 
as well to avoid having to wrap headings.

One think I didn't struggle with was github. When I'm working on smaller solo projects such as this one I tend to not commit as often which
is something I could improve on. I was lucky enough to take a class on git and github so I was easily able to execute any commands. Another thing
I was proud of was my effective use of the dev tools to solve issues. I fell into a common rhythm of recognizing when the css was not properly applying or 
when margins and padding were causing issues. To fix these I turned to the inspect tool to figure out what to change. Laying out the desktop and mobile
screen separately was not an issue for me. I ran into more of a struggle converting back and forth.

I do feel like I grasp a solid understanding on the concepts you have introduced in the class. As I discussed above, I was able to solve
all issues that arose through inspection. My grasp of hierarchy, reflexive behavior, flexbox behavior, and other skills
I learned in this class allowed me to fix most issues I found in a timely manner. I can easily identify if I nested something incorrectly or
if css had any conflictions because of my foundational knowledge of css and html. The reflexive behavior and switching between the two viewports
was tricky at first but once adapting the order in which I built up the website I was able to work more efficiently on the project.

In the future I hope to work in UX and UI design so the concept of reflexive layouts is fundamental. For a website to not only be readable but effective
in 2026 it is necessary to design from the mobile viewpoint as well as desktop. The different methods of use affect how a user interacts with common elements 
such as menus, buttons, text, and photos. This concept has been touched on in my other classes, but I am someone who likes to work hands on with concepts.
By implementing this website it helps me visualize how a layout might shift to best serve the user in the different ways they interact with a site. I am 
excited to learn how to take these concepts, build them with vue, and build a site with a partner.

There are a few things I would like to revisit with this project. I tried to organize my css page as well as I could but due to time constraints I believe it 
could be refactored further. If I had time I would have also like to explore building out my layout I made on figma and I am excited to try some of those
skills in the future with the final project. Using vue will be extremely convenient as it will save time (like having to go into last minute and add links to every
html page because there is no way to change them all at once) and repeated code. Can't wait!
